# Security

TokenLuma processes Claude Code transcript files, which may contain sensitive prompts, source code, tool output, and local file paths.

Please do not report vulnerabilities publicly with sensitive details. Use GitHub's **Report a vulnerability** feature on the repository's Security tab when it is available. Include a concise description, impact, and reproduction steps that do not expose real transcript contents. If that feature is not enabled, open a minimal public issue asking for a private reporting channel without disclosing the vulnerability details.
